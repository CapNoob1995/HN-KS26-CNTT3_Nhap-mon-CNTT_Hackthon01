# Steam Game Store Manager

Dự án này giúp quản lý danh sách **Game Steam** ưa thích và *tối ưu hóa* trải nghiệm tra cứu dữ liệu trò chơi.

## Cấu trúc thư mục

|Thư mục|Nội dung|
|-|-|
|`docs`|Tài liệu hướng dẫn sử dụng và báo cáo hệ thống|
|`data`|Lưu trữ file thông tin game, giá vật phẩm và đánh giá|
|`media`|Chứa hình ảnh poster, banner và screenshot|

## Kiểm tra cấu trúc dự án

```powershell
Get-ChildItem -Recurse -Force
```
